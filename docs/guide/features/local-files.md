# 本地文件操作

WorkBuddy 支持安全地访问和操作您的本地文件，实现文档处理、数据分析和文件管理等任务的自动化。

## 安全访问机制

### 授权原则

WorkBuddy 采用**显式授权**机制：

- **最小权限**: 仅访问任务必需的文件夹
- **用户控制**: 您可以随时添加、修改或撤销授权
- **操作透明**: 所有文件操作都会记录并告知您
- **本地优先**: 文件始终保留在您的设备上

### 授权流程

```
用户请求文件操作
       ↓
WorkBuddy 请求授权
       ↓
用户确认授权范围
       ↓
在限定范围内执行
       ↓
完成任务后释放（可选）
```

### 授权管理

在设置中可以管理授权：

- **查看已授权文件夹**: 查看当前授权的工作目录
- **添加新授权**: 选择需要 WorkBuddy 访问的文件夹
- **修改权限**: 扩大或缩小授权范围
- **撤销授权**: 立即移除特定文件夹的访问权限

## 支持的文件操作

### 读取操作

| 操作 | 说明 | 应用场景 |
|-----|------|---------|
| 读取文档 | 读取 Word, PDF, Markdown 等 | 分析文档内容、提取信息 |
| 读取表格 | 读取 Excel, CSV 数据 | 数据分析、报表生成 |
| 读取文本 | 读取代码、日志、笔记 | 代码分析、日志检查 |
| 读取图片 | OCR 识别图片文字 | 图片信息提取 |
| 读取目录 | 扫描文件夹结构 | 文件整理、批量处理 |

### 写入操作

| 操作 | 说明 | 应用场景 |
|-----|------|---------|
| 创建文件 | 生成新文档 | 报告输出、文档创作 |
| 修改文件 | 编辑现有文件 | 内容更新、格式调整 |
| 导出数据 | 保存处理结果 | 数据导出、备份存档 |

### 管理操作

| 操作 | 说明 | 应用场景 |
|-----|------|---------|
| 移动/复制 | 调整文件位置 | 文件整理、分类归档 |
| 重命名 | 修改文件名称 | 规范命名、批量处理 |
| 删除 | 移除文件（需确认） | 清理临时文件 |
| 压缩/解压 | 打包或解压文件 | 文件传输、批量备份 |

## 典型应用场景

### 场景 1：周报自动生成

**流程**:
```
1. WorkBuddy 读取授权的工作记录文件夹
2. 分析本周的工作日志、会议记录等
3. 整理关键成果和进展
4. 生成周报文档
5. 保存到指定输出目录
```

**用户只需**: 一句话下达指令，确认授权

### 场景 2：销售数据分析

**流程**:
```
1. 读取指定文件夹中的销售数据 Excel 文件
2. 分析销售趋势和区域分布
3. 生成可视化图表
4. 输出分析报告到输出目录
```

**支持功能**:
- 自动识别数据文件
- 处理多个数据源
- 增量分析（只处理新数据）

### 场景 3：文件批量整理

**指令示例**:
> "把下载文件夹里的所有 PDF 文件移动到归档文件夹，并按月份分类"

**执行过程**:
1. 扫描下载文件夹
2. 识别所有 PDF 文件
3. 读取文件日期信息
4. 在归档文件夹创建月份子文件夹
5. 移动文件到对应位置
6. 生成操作日志

### 场景 4：项目文档整合

**指令示例**:
> "把项目文件夹里的需求文档、设计稿、会议纪要整合成一份项目总结"

**执行过程**:
1. 扫描项目文件夹结构
2. 识别各类文档
3. 提取关键信息
4. 按时间线整理
5. 生成综合项目文档

## 路径引用方式

### 相对路径（推荐）

基于已授权的工作目录引用：

```
"读取 data/ 目录下的销售报表"
"把结果保存到 output/ 文件夹"
"分析 projects/website/ 下的代码"
```

优势：
- 简洁清晰
- 不受绝对路径变化影响
- 便于团队协作共享指令

### 绝对路径

使用完整路径：

```
"读取 C:\Users\Name\Documents\report.xlsx"
"保存到 /home/user/projects/output/"
```

适用场景：
- 临时访问特定位置
- 处理系统级文件

### 智能路径识别

WorkBuddy 支持模糊路径引用：

```
"桌面上那份周报"          → 自动定位桌面文件夹
"下载文件夹里的最新 Excel" → 自动识别最新文件
"项目文件夹"              → 匹配名称包含"项目"的文件夹
```

## 隐私与安全

### 数据处理原则

- **本地优先**: 文件内容主要在本机处理
- **最小上传**: 仅在必要时（如云端 AI 处理）上传部分数据
- **加密传输**: 所有网络传输采用加密
- **无持久存储**: 不在服务端长期保存文件内容

### 您可以控制的内容

✅ **完全可控**:
- 哪些文件夹可以被访问
- 访问权限的持续时长
- 是否允许云端处理

❌ **不会执行**:
- 访问未授权的文件夹
- 修改系统关键文件
- 执行可疑的文件操作

### 建议的安全实践

1. **分目录授权**
   - 工作文件: 完全授权
   - 个人文件: 按需临时授权
   - 敏感文件: 不授权或脱敏后处理

2. **定期审查**
   - 定期查看已授权的目录
   - 移除不再需要的授权

3. **敏感数据处理**
   - 涉及密码、密钥的文件建议不要授权
   - 客户隐私数据处理后及时清理临时文件

## 常见问题

### Q: WorkBuddy 会不会删除我的重要文件？

**A**: 不会。删除操作需要您的明确确认，且 WorkBuddy 会主动规避：
- 系统关键目录
- 大量文件删除请求
- 可疑的删除模式

### Q: 可以同时授权多个文件夹吗？

**A**: 可以。您可以授权多个工作目录，WorkBuddy 会在不同任务中按需访问。

### Q: 移动设备上的文件可以处理吗？

**A**: 目前支持桌面端（Windows/macOS/Linux）。移动端文件可通过云同步后在桌面端处理。

### Q: 大文件处理会卡吗？

**A**: WorkBuddy 会：
- 对大文件采用流式处理
- 自动分块读取超大型文件
- 提前提示处理时间预估
- 支持后台处理不阻塞界面

### Q: 可以处理网络共享文件夹吗？

**A**: 可以。只要该网络位置在您的系统中被映射为本地盘符或挂载点。
