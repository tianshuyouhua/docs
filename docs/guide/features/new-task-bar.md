# 新建任务栏

学习如何使用新建任务栏快速创建和管理任务。

## 新建任务栏概述

新建任务栏是 WorkBuddy 主界面的核心入口，提供快速创建任务的功能。

## 使用方法

### 快速创建

1. 点击主界面顶部的「新建任务」按钮
2. 在输入框中输入任务描述
3. 按回车或点击发送按钮

### 高级创建

- 点击「+」按钮展开高级选项
- 选择任务类型（文档/数据/PPT/文件处理）
- 设置优先级和截止时间

## 任务栏快捷操作

| 操作 | 快捷方式 |
|-----|---------|
| 新建任务 | Ctrl/Cmd + N |
| 搜索历史任务 | Ctrl/Cmd + K |
| 查看任务列表 | Ctrl/Cmd + L |
| 切换任务 | Ctrl/Cmd + Tab |

## 任务栏设置

在设置中可以自定义：
- 任务栏位置（顶部/侧边）
- 默认任务类型
- 常用指令模板
