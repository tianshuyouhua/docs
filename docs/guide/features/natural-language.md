# 理解自然语言

WorkBuddy 的核心优势在于能够理解自然语言指令，让您像与同事交流一样轻松下达任务。

## 为什么自然语言交互很重要

传统的 AI 工具往往需要学习特定的指令格式或关键词。WorkBuddy 打破了这种限制：

- **无需记忆指令**: 不需要学习固定的命令语法
- **灵活表达方式**: 同一需求可以有多种表达方式
- **上下文理解**: 能够理解对话的上下文和隐含意图

## 高效下达指令的技巧

### 1. 提供充分的背景信息

**一般表达**:
> "写一份产品分析报告"

**更好的表达**:
> "针对我们的 SaaS 产品，分析过去一个月的活跃用户数据变化，找出可能的原因，并给出优化建议。报告面向产品团队，需要包含数据图表。"

### 2. 明确输出格式和质量要求

**一般表达**:
> "整理会议纪要"

**更好的表达**:
> "将这份会议录音整理成结构化的纪要，包含：
> 1. 会议基本信息（时间、参会人、议题）
> 2. 达成的决议事项
> 3. 分配的任务清单（负责人+截止时间）
> 4. 待确认的问题
> 输出为 Markdown 格式，便于导入 Notion。"

### 3. 举例说明期望结果

当 WorkBuddy 对您的需求不确定时，举例是最有效的澄清方式：

> "帮我写一封跟进邮件，语气类似这样：'您好，想跟进一下上周讨论的方案...'"

### 4. 分步骤下达复杂任务

对于多阶段任务，可以先给出整体目标，再逐步细化：

> **第一步**: "帮我制定一个新产品发布计划的整体框架"
> 
> **第二步**: "针对预热阶段，设计具体的社媒推广内容"
> 
> **第三步**: "为发布会准备一份演讲 PPT 大纲"

## WorkBuddy 能理解的指令类型

### 文档创作类

```
"写一份..."
"帮我起草..."
"基于这些数据生成报告..."
"将以下内容整理成..."
```

### 数据处理类

```
"分析这份数据..."
"将这些文件..."
"对比 A 和 B..."
"找出数据中的..."
```

### 信息整理类

```
"搜索...并整理成..."
"调研...方面的信息"
"总结这篇文章的要点"
"从这份资料中提取..."
```

### 格式转换类

```
"将 Word 转换成 PDF"
"把这些 Excel 文件合并"
"提取 PPT 中的文字内容"
"批量重命名这些文件"
```

## 对话式协作

WorkBuddy 不仅支持单次指令，还支持持续的对话协作：

### 跟进任务进度

> "进度怎么样了？"
> "这一步完成了吗？"
> "遇到什么困难了吗？"

### 调整任务方向

> "等等，我觉得第二部分的侧重点应该放在..."
> "这部分内容可以删除，重点加强..."
> "能否换个角度，从用户视角来写？"

### 追加需求

> "对了，还需要加上..."
> "能不能顺便..."
> "在此基础上，再帮我..."

## 常见误区与建议

### ❌ 避免过于模糊的描述

> ~~"帮我做点东西"~~

**改进**: 明确具体要做什么、给谁看、达到什么目的

### ❌ 避免一次下达过多需求

> ~~"帮我写周报、做 PPT、整理数据还要发邮件"~~

**改进**: 分批次下达，或明确优先级

### ❌ 避免使用过多的专业缩写

> ~~"优化 Q3 OKR 的 KR 达成率"~~

**改进**: 除非确认 WorkBuddy 了解这些术语，否则建议展开说明

### ✅ 推荐使用结构化表达

```
【任务目标】: ...
【背景信息】: ...
【具体要求】: ...
【输出格式】: ...
【注意事项】: ...
```

## 多轮对话示例

以下是一个完整的任务协作对话示例：

---

**用户**: "帮我准备下周一的产品评审会材料"

**WorkBuddy**: "好的，我来帮您准备产品评审会材料。为了更有针对性地准备，能否告诉我：
1. 评审的是哪个产品/功能？
2. 参会人员主要关注哪些方面？
3. 需要包含哪些材料（如数据报告、演示文稿等）？"

**用户**: "评审的是新上线的数据分析模块。参会的是技术负责人和产品总监。需要一份功能演示 PPT 和用户反馈数据汇总。"

**WorkBuddy**: "明白了。我会准备：
1. 数据分析模块的功能演示 PPT（包含核心功能介绍和使用场景）
2. 用户反馈数据汇总（包含满意度统计和典型反馈整理）

预计 20 分钟完成。开始执行吗？"

**用户**: "好的，PPT 的色调用我们品牌蓝色系"

**WorkBuddy**: "收到，会使用蓝色系色调设计 PPT。开始执行..."

---

## 持续学习能力

WorkBuddy 具备持续学习您偏好表达习惯的能力：

- **记住常用术语**: 您常用的行业术语会被记录
- **理解个人风格**: 逐渐适应您的表达习惯和偏好
- **复用成功模式**: 之前执行成功的任务模式会被参考

您可以随时通过「偏好设置」来管理这些学习记录。
