# 开启你的第一个任务

准备好创建您的第一个 WorkBuddy 任务了吗？跟着这个简单的指南开始吧。

## 第一步：启动 WorkBuddy

双击桌面图标启动应用，您会看到简洁的主界面。

## 第二步：用一句话描述任务

在输入框中输入您的需求，例如：

> "帮我整理桌面文件，按文件类型分类到不同文件夹"

## 第三步：确认执行计划

WorkBuddy 会自动分析需求并展示执行计划，确认无误后点击「开始执行」。

## 第四步：等待成果

任务执行过程中可以：
- 查看实时进度
- 调整执行要求
- 暂停或取消任务

## 第五步：验收成果

任务完成后，检查交付的成果是否符合预期。

## 常用入门任务

### 文档处理
- "帮我把这份销售数据生成分析报告"
- "整理会议纪要，提取待办事项"

### 文件管理
- "把下载文件夹的文件按日期整理"
- "批量重命名这些截图文件"

### 数据分析
- "分析这个 Excel 文件，找出增长最快的产品"
- "对比上季度和本季度的销售数据"
