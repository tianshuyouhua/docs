# 任务管理

有效管理多个任务，追踪进度，确保工作高效有序地进行。

## 任务生命周期

```
创建 → 规划 → 执行 → 监控 → 完成/取消
  ↑___________________________↓ (反馈优化)
```

### 任务状态

| 状态 | 说明 | 可操作 |
|-----|------|-------|
| 待开始 | 已创建，等待执行 | 编辑、删除、立即执行 |
| 规划中 | 正在拆解任务步骤 | 查看规划、修改要求 |
| 执行中 | 正在进行处理 | 暂停、取消、查询进度 |
| 已暂停 | 执行被暂停 | 继续、取消 |
| 已完成 | 成功交付成果 | 查看结果、重新执行 |
| 已取消 | 被用户取消 | 查看历史、重新创建 |
| 执行失败 | 遇到无法解决的问题 | 查看原因、重试、调整 |

```
✅ 数据读取完成
✅ 数据清洗完成
✅ 统计分析完成
⏳ 可视化制作中
⏸ 报告撰写等待中

当前操作：生成趋势图表 (3/5)
```

### 任务操作

| 操作 | 说明 | 使用场景 |
|-----|------|---------|
| 开始 | 启动待执行的任务 | 手动控制执行时机 |
| 暂停 | 暂时停止执行 | 需要调整要求或处理紧急事项 |
| 继续 | 恢复暂停的任务 | 从断点继续执行 |
| 取消 | 终止任务执行 | 需求变更或不再需要 |
| 重试 | 失败任务再次尝试 | 问题解决后重新执行 |
| 复制 | 基于现有任务创建新任务 | 类似需求的快速创建 |

### 修改进行中的任务

执行过程中仍可调整：

```
用户: "周报任务，业绩部分再加一个同比数据"
WorkBuddy: "收到，在当前步骤完成后补充同比分析"

用户: "PPT 任务暂停一下，我先确认数据"
WorkBuddy: "已暂停。当前进度：大纲已完成，设计部分未开始。可随时继续。"
```

## 批量任务管理

### 批量操作

选中多个任务进行批量操作：

```
- 批量暂停/继续
- 批量取消
- 批量导出记录
- 批量删除（仅已完成/已取消）
```

### 任务分组

按项目或类型组织任务：

```
📁 产品发布项目
   ├── 竞品分析报告
   ├── 产品介绍 PPT
   └── 发布通知邮件

📁 日常运营
   ├── 周报生成
   ├── 数据统计
   └── 内容更新
```

### 任务优先级

设置优先级管理执行顺序：

```
🔴 高优先级 - 立即处理
🟡 中优先级 - 正常排队
🟢 低优先级 - 空闲时处理
```

设置方式：

```
"这是一个紧急任务，高优先级"
"明天开会要用，请优先处理"
"这个不急，可以慢慢做"
```

## 任务冲突与调度

### 资源冲突处理

当多个任务需要同一资源时：

```
场景: 
- 任务 A: 分析 sales.xlsx (执行中)
- 任务 B: 也需要修改 sales.xlsx

WorkBuddy:
"检测到文件 sales.xlsx 正被任务 A 使用。
选项：
1. 等任务 A 完成后再执行 B
2. 暂停 A，优先执行 B
3. 为 B 创建文件副本
请选择处理方式"
```

### 优先级调度

高优先级任务可以抢占资源：

```
当前执行: 文档整理（低优先级）
新任务: 紧急会议材料准备（高优先级）

处理:
1. 暂停文档整理
2. 执行会议材料准备
3. 完成后恢复文档整理
```

## 任务管理最佳实践

### 1. 合理拆分大任务

```
❌ 单一大任务："准备产品发布会"

✅ 拆分为多个小任务：
- 竞品分析报告
- 产品介绍 PPT  
- 发布会流程策划
- 宣传物料设计
- 演讲稿撰写
```

### 2. 设置明确的截止时间

```
"这份报告周三下午 5 点前需要"
"PPT 明天上午 10 点开会用"
"周报不急，周五下班前完成就行"
```

### 3. 定期检查任务状态

养成习惯：
- 每天早会前查看今日任务
- 每天下班前确认无遗漏
- 每周回顾完成情况和效率

### 4. 及时清理已完成任务

```
- 归档有价值的任务记录
- 删除临时性任务
- 整理成功模板供复用
```

### 5. 关注失败任务

```
查看失败原因：
- 需求不明确 → 改进指令
- 资源不可用 → 检查授权
- 超出能力范围 → 分解为子任务
```
