# Claw 远程控制

通过 Claw 实现远程操控其他设备执行任务，打破设备间的物理边界。

## 什么是 Claw？

Claw 是 WorkBuddy 的远程控制功能模块，允许您从当前设备远程操控其他已授权的设备执行任务。

## 使用场景

- 远程访问办公室电脑处理文件
- 在出差途中操控家中设备
- 多设备协同完成复杂任务

## 连接设置

### 添加远程设备

1. 在目标设备上安装 WorkBuddy 并登录
2. 进入设置 → 远程控制 → 生成连接码
3. 在控制端设备输入连接码完成配对

### 安全机制

- 端到端加密通信
- 双向授权确认
- 随时可撤销连接
