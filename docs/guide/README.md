# 入门指南

欢迎使用 WorkBuddy 文档中心！这里包含了从基础入门到高级使用的完整指南。

## 关于 WorkBuddy

WorkBuddy 是腾讯推出的全场景职场 AI 智能体桌面工作台，面向各类职能角色设计。您只需用一句话描述需求，WorkBuddy 便能像同事一样自主规划和执行任务，并交付可验收的结果。

## 建议阅读顺序

如果您是第一次使用 WorkBuddy，建议按照以下顺序阅读：

1. **快速开始** - 完成环境准备和首次体验
2. **理解自然语言** - 学习如何高效下达指令
3. **创建任务** - 掌握各类任务的创建方法
4. **任务管理** - 学会追踪和管理任务

## 与传统 AI 对话的区别

| 维度 | 传统 AI 对话 | WorkBuddy |
|------|-------------|-----------|
| 交互方式 | 一问一答 | 一句话下达复杂任务 |
| 执行能力 | 仅提供建议 | 自主规划并执行 |
| 结果交付 | 文本回复 | 可验收的完整成果 |
| 持续协作 | 单轮对话 | 持续跟进直至完成 |
