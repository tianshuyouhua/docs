# 更新日志

本页面记录了 WorkBuddy 的所有重要更新和改进。

## v1.2.0 (2026-05-01)

### ✨ 新功能

- **批量文件处理增强**: 支持更多文件格式转换，新增图片压缩和重命名规则自定义
- **数据源扩展**: 新增连接飞书文档、腾讯文档等在线协作平台
- **任务模板市场**: 用户可以分享和下载他人创建的任务模板
- **定时任务**: 支持设置周期性自动执行的任务

### 🚀 优化

- 提升大文件处理速度，PDF 合并速度提升 40%
- 优化自然语言理解，复杂任务拆解准确率提升至 92%
- 改进多步骤任务的中断恢复机制

### 🐛 修复

- 修复 Windows 系统下长路径文件无法读取的问题
- 修复某些特殊字符导致任务中断的异常
- 修复暗色模式下部分 UI 显示异常

## v1.1.0 (2026-03-15)

### ✨ 新功能

- **远程控制功能**: 支持通过 Claw 远程操控其他设备执行任务
- **PPT 智能生成**: 根据大纲自动生成带设计样式的演示文稿
- **会议纪要智能提取**: 从音频/视频/文字记录中提取关键信息

### 🚀 优化

- 重构任务调度引擎，支持更多并行任务
- 优化内存占用，长时间运行更稳定
- 改进中文自然语言处理，方言识别准确率提升

## 版本说明

### 版本号规则

我们使用语义化版本号（SemVer）：

- **主版本号** (x.0.0): 重大更新，可能包含不兼容的 API 变更
- **次版本号** (0.x.0): 新增功能，向后兼容
- **修订号** (0.0.x): 问题修复，向后兼容

### 更新方式

- **自动更新**: 默认开启，有新版本时自动下载并提示安装
- **手动检查**: 点击菜单「帮助」→「检查更新」
- **离线安装**: 从官网下载完整安装包覆盖安装
