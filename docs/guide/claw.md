# Claw

Claw 是 WorkBuddy 的远程控制模块，支持跨设备任务执行。

## 功能特性

- **远程连接**: 安全连接其他已授权设备
- **任务派发**: 在远程设备上执行任务
- **状态同步**: 实时查看远程任务进度
- **文件传输**: 安全传输任务相关文件

## 使用流程

1. 在目标设备安装 WorkBuddy
2. 生成并交换连接码
3. 确认双向授权
4. 开始远程任务执行

## 安全说明

- 所有通信端到端加密
- 需要双向授权确认
- 随时可断开连接
- 操作记录完整可追溯
