# 快速开始

本指南将帮助您在 5 分钟内上手 WorkBuddy，完成从安装到创建第一个任务的完整流程。

## 一、环境准备

### 系统要求

- **操作系统**: Windows 10/11, macOS 10.15+, 或主流 Linux 发行版
- **内存**: 至少 4GB RAM（推荐 8GB）
- **存储**: 至少 1GB 可用空间
- **网络**: 稳定的互联网连接

### 安装步骤

1. **下载安装包**
   - 访问 [WorkBuddy 官网](https://workbuddy.tencent.com) 下载对应系统的安装包
   - 或使用包管理器安装：
     ```bash
     # macOS (Homebrew)
     brew install workbuddy
     
     # Windows (Winget)
     winget install Tencent.WorkBuddy
     ```

2. **运行安装程序**
   - Windows: 双击 `.exe` 安装包，按向导完成安装
   - macOS: 将应用拖拽到 Applications 文件夹
   - Linux: 解压并运行安装脚本

3. **完成初始化**
   - 首次启动时，使用腾讯账号登录
   - 授权必要的系统权限（文件访问等）
   - 完成新手引导教程

## 二、开启您的第一个任务

### 步骤 1: 启动 WorkBuddy

双击桌面图标或通过开始菜单启动应用。您会看到简洁的主界面：

- 顶部：输入框，用于下达任务指令
- 中间：任务列表区域
- 右侧：任务详情面板

### 步骤 2: 用自然语言创建任务

在输入框中输入您的需求，例如：

> "帮我写一份关于人工智能发展趋势的周报，需要包含行业动态、技术突破和应用案例三个部分"

### 步骤 3: 查看任务规划

WorkBuddy 会自动分析您的需求并展示任务规划：

1. **搜索行业动态** - 搜集本周 AI 领域重要新闻
2. **整理技术突破** - 汇总最新研究进展
3. **收集应用案例** - 整理典型应用实例
4. **生成周报文档** - 整合内容并格式化输出

### 步骤 4: 确认并执行

查看规划是否符合预期：
- 点击「确认执行」开始自动处理
- 或点击「修改规划」调整任务步骤

### 步骤 5: 验收成果

任务完成后，WorkBuddy 会：
- 在对话中展示成果摘要
- 提供生成的文档下载链接
- 询问是否需要调整或继续迭代

## 三、常用指令示例

### 文档类任务

```
"根据这份销售数据，生成一份季度分析报告，包含图表和趋势预测"
```

## 四、核心功能详解

### 1. 任务对话模式

创建任务后，您可以随时：
- 询问执行进度
- 调整任务要求
- 追加新的需求
- 暂停或取消任务

### 2. 文件操作授权

WorkBuddy 需要您授权访问本地文件夹：
- 在设置中配置「工作目录」
- 可以指定多个常用文件夹
- 可随时修改或撤销授权

### 3. 结果交付形式

根据任务类型，成果可能以以下形式交付：
- 📄 Word/Excel/PPT 文档
- 📊 数据可视化图表
- 📧 邮件正文
- 📋 任务清单或表格
- 📝 Markdown 文本

## 五、常见问题

### Q: WorkBuddy 会保存我的文件和数据吗？

**A**: 您的本地文件始终保留在您的设备上。WorkBuddy 仅在执行任务时临时读取，不会在云端保留副本（除非您主动选择云端备份功能）。

### Q: 任务执行过程中可以中断吗？

**A**: 可以。在任务详情页点击「暂停」按钮，或发送消息"先停一下"。中断的任务可以稍后从断点继续。

### Q: 一次可以创建多个任务吗？

**A**: 可以。WorkBuddy 支持并行执行多个独立任务。在任务列表中可以查看所有进行中和已完成的任务。

### Q: 如何提升任务执行效果？

**A**: 建议：
1. 描述需求时提供充分的背景信息
2. 明确输出格式和质量要求
3. 举例说明您期望的结果样式
4. 对于复杂任务，建议分步骤下达

### Q: 遇到任务执行失败怎么办？

**A**: 您可以：
1. 查看错误详情，了解失败原因
2. 根据提示补充必要信息
3. 调整后重新执行
4. 或在对话中询问 WorkBuddy 寻求帮助
