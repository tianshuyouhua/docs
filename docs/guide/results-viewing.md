# 结果查看

任务完成后，查看和验收 WorkBuddy 交付的成果。

## 查看任务结果

### 成果展示

任务完成后，WorkBuddy 会：
- 在对话中展示成果摘要
- 提供文件下载链接
- 展示关键数据和统计信息

### 成果类型

| 类型 | 查看方式 |
|-----|---------|
| 文档 | 在线预览 + 下载 |
| 数据报表 | 交互式图表 |
| PPT | 幻灯片预览 |
| 代码 | 语法高亮预览 |

## 验收与反馈

### 检查成果

- 确认内容是否符合预期
- 检查数据准确性
- 验证格式和排版

### 反馈迭代

如果不满意，可以直接提出修改要求：
- "数据部分需要更新到最新"
- "格式调整一下，更简洁一些"
- "再加一个对比分析的章节"

## 成果管理

- **下载保存**: 将成果保存到本地
- **分享**: 生成分享链接
- **归档**: 将成果归档到项目文件夹
